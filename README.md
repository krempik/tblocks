# T-Blocks v2.0

Продвинутый Tetris++ с боссами, powerups, достижениями и лидербордом.

## Запуск

Открой `index.html` в браузере. Всё на одном файле — никаких зависимостей.

## Режимы

| Режим | Описание |
|-------|----------|
| **Классический** | Тетрис как ты его знаешь, но лучше. Комбо, бонусы, вызов |
| **Марафон** | Бесконечный режим. Скорость растёт. Держись как можно дольше! |
| **Битва с Боссом** | Уничтожай линии, чтобы нанести урон боссу. Он отвечает! |
| **Ультра** | 2 минуты. Максимум очков. Бонусы падают чаще |

## Боссы

| Босс | HP | Атака | Урон |
|------|-----|-------|------|
| **Кубик Хаоса** | 325 | каждые 260 тиков | +1 ряд |
| **Призма Тьмы** | 520 | каждые 180 тиков | +2 ряда |
| **Тетроментор** | 780 | каждые 130 тиков | +3 ряда |

Каждый босс периодически проталкивает поле вверх, добавляя мусорный ряд снизу.

## Темы

- **Matrix** — зелёный на чёрном
- **Neon** — яркие неоновые цвета
- **Retro** — 8-bit палитра
- **Mono** — чёрно-белая

## Сервер (лидерборд)

```bash
pip install -r requirements.txt
python server.py
```

Сервер запускается на `http://localhost:8001`.

### API

| Метод | Эндпоинт | Описание |
|-------|-----------|----------|
| `POST` | `/api/score` | Отправить счёт |
| `GET` | `/api/leaderboard?mode=classic` | Таблица лидеров |
| `GET` | `/api/stats` | Статистика |

### Cloudflare Tunnel

Сервер автоматически запускает Quick Tunnel (если `cloudflared` установлен).

## Стек

- **Игра:** HTML5 Canvas, Web Audio API, Vanilla JS (~1400 строк)
- **Сервер:** Python, FastAPI, SQLAlchemy, SQLite
